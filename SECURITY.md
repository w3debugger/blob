# Security Policy

Blob is a macOS utility that moves files to the Trash. Reports about data loss, unintended deletion, or any other security issue are taken seriously.

## Supported versions

The latest release on `main` is the supported version.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | yes       |

## Reporting a vulnerability

Please report security issues **privately**, not in a public issue.

- Preferred: open a private report through GitHub's [Security Advisories](https://github.com/w3debugger/blob/security/advisories/new) using "Report a vulnerability". This keeps the discussion private until a fix is available.

Please include:

- what happened,
- steps to reproduce,
- your macOS version,
- the impact (for example, files that were deleted but should not have been).

Reports are typically acknowledged within a few days. Thank you for helping keep Blob safe.
