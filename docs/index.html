// reap dead disk space.

A tiny terminal-green disk cleaner for macOS. It hunts the big stuff, shows you every path before it touches it, and moves things to the Trash, never a blind delete. Three honest modes. Nothing running in the background.

files

biggest single files

Point it at any folder, set a size floor, and it surfaces the heaviest individual files on disk, the forgotten ISOs, video exports, and 4 GB log files.

// files mode finds individual large files
dirs

fat folders by name

Finds directories by name and ranks them by total recursive size. Built for hunting node_modules, build, target, .gradle scattered across every project.

// watching: node_modules, dist, .next, Pods, target…
dev

developer caches

One tap inventories the regenerable junk: Xcode DerivedData & simulators, npm / yarn / pnpm, gradle, cargo, Homebrew. Only caches that rebuild themselves, never your archives or data.

// Trash, not rm -rf

No menubar resident. No "watching" your Trash in the background. No phone-home. Blob opens, scans when you say scan, shows the full path of every byte, and moves selected items to the Trash so you can change your mind. Then it gets out of the way.
